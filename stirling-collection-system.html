🔌 RESTful API Endpoints
Base: https://api.stirling.wa.gov.au/cis/v1/waste
GET /bookings ● 200
Fetch all pending resident bookings from portal
GET /bookings/{id} ● 200
Get single booking detail by ID
POST /bookings/{id}/status ● 201
Push collection status update to City (collected/missed/rescheduled)
POST /collections/complete ● 201
Submit completed collection record with timestamp and items
GET /residents/{id}/allowance ● 200
Check resident's annual allowance utilisation
POST /reports/monthly ● 202
Submit pre-approved monthly report (JSON/CSV)
PUT /bookings/{id}/reschedule ● 200
Reschedule missed collection; triggers resident notification
GET /zones/{zone}/schedule ● 200
Get all upcoming bookings for East or West zone
🔐 Security & Authentication
ProtocolOAuth 2.0 / OIDC
Token TypeJWT Bearer (RS256)
Token Expiry3600s + refresh
TransportTLS 1.3 (HTTPS only)
API Key Rotation90-day cycle
IP AllowlistContractor CIDR
Rate Limit1000 req/hr
Privacy Scoperead:bookings write:status
📦 Data Formats
Primary FormatJSON (UTF-8)
Backup TransferSFTP / CSV (daily)
Date FormatISO 8601
AddressesGNAF standard (G-NAF)
Versioning/v1/ in path + header
Paginationcursor-based
⚠️ Error Handling
400 Bad Request Validation error
401 Unauthorized Re-authenticate
404 Not Found Booking not found
429 Rate Limited Backoff + retry
500 Server Error Fallback to SFTP
